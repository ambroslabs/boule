> **boule** — from the ancient Greek *βουλή* (boulē, /buːˈleɪ/, "boo-LAY"),
> the citizen council of classical Athens that deliberated to reach
> collective decisions. A fitting namesake for a Byzantine-fault-tolerant
> consensus system.
